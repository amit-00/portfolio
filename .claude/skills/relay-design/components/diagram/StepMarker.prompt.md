# StepMarker

A 20px numbered square seated on an edge, giving the figure a reading order. This is what
carries sequence in print, where the flow pulse does not exist — so any diagram whose
argument depends on order needs markers, not just motion.

Seat it on the line, not beside it: the square's page-coloured fill breaks the stroke.

```jsx
<StepMarker n={2} x={112} y={194} />
```
