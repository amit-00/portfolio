# Button

Mono-label action button; use for the few real actions on a docs page (copy, run, subscribe) — never for navigation, which is plain link text.

```jsx
<Button variant="primary" size="md">Copy snippet</Button>
```

Variants: primary (solid ink), secondary (hairline box), ghost (text only). Sizes sm/md. Labels are uppercase mono by default; set uppercase={false} for sentence case.
