# TopBar

The one persistent chrome element; everything else on the page scrolls.

```jsx
<TopBar breadcrumb="docs / deep-dive / change-capture" right={<><span>\u2318K search</span><Badge>v3.2</Badge></>} />
```

Breadcrumb uses lowercase slugs with slashes, not chevrons. The bottom rule is full ink weight — the strongest rule on the page.
