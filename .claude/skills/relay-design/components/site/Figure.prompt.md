# Figure

Frames one artefact inside an article or case study and numbers it. Pair with `DiagramPlaceholder` until a real asset exists.

```jsx
<Figure index="FIG 02" caption="Envelopes hash to a partition by primary key.">
  <DiagramPlaceholder label="diagram — partition hashing" height={220} />
</Figure>
```

`tone="inverse"` when the framed thing is code or a dark still.
