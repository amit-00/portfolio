# SiteFooter

Closes a portfolio, article or docs page with a full-ink rule, the type wordmark and up to three mono link columns.

```jsx
<SiteFooter
  note="Written and built in London. Last deploy 2026-07-28."
  groups={[{ title: "Elsewhere", links: ["github", "rss", "email"] }]}
/>
```

Two or three groups maximum; the footer is a colophon, not a sitemap.
